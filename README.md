# Bad Time Editor

一个专为 **Bad Time Simulator** (及类似 Construct 2 导出的 Sans 战斗引擎) 设计的**可视化弹幕时间轴编辑器**。

告别手写繁杂的 CSV 坐标和逻辑跳转，通过拖拽和图形化界面，轻松创建、预览并导出属于你的弹幕！

---

## 特性

- **双模式编辑**：
  - **拖拽模式**：所见即所得，直接在画布上拖拽生成骨头、龙骨炮、战斗框，实时调整参数。
  - **脚本模式**：提供代码编辑器，支持语法高亮、行号显示及指令自动补全（如 `$变量`、`JMP`）。
- **时间轴系统**：直观展示弹幕发生的时间顺序，点击时间轴节点即可快速修改该指令的延迟和参数。
- **国际化支持**：内置 **中文 / English** 无缝切换。
- **自动音效挂载**：生成 `SansSlam` 等指令时，自动附带关联音效指令，省去手动添加的麻烦。

---

## 快速开始

### 1. 运行编辑器
无需安装任何依赖或启动本地服务器，直接用现代浏览器（Chrome / Edge / Firefox）打开 `index.html` 即可。

### 2. 创建你的弹幕
1. 点击底部的指令卡片（如“龙骨炮”、“水平骨头”）。
2. 拖拽到中间的画布区域释放。
3. 点击画布上的图形，在弹出的参数面板中调整坐标、速度、延迟时间等。
4. 在下方的“时间轴”中查看弹幕的先后顺序。

### 3. 导出并在游戏中测试
- 点击右上角的 **「保存 CSV」**。
- 将导出的 `custom_attack.csv` 放入你的游戏根目录。
- 修改游戏本体的 `data.js`（参考下方“接入游戏”），将该文件注册进单发攻击菜单或随机池中。
